# CLAUDE.md

## Проект

- Лендинг личной CRM: одна страница, одно целевое действие - перейти в приложение
- Приложение - отдельный репозиторий, адрес `https://app.<мой домен>`
- Макет - `design/`: HTML-файлы - образец вида, `design/README.md` - токены, экраны, тексты. Стек и правила - из этого файла, при расхождении прав он

## Как со мной работать

- Отвечай по-русски, простыми словами: я не разработчик
- Тексты лендинга - дословно из макета; менять текст - только с моего согласия
- Сделал - открой в моём браузере и покажи скриншот на телефоне и компьютере

## Язык кода

- Код и всё, что к нему относится, - на английском: имена файлов, переменных, комментарии, коммиты
- На русском - только тексты страницы

## Стек

- Astro, Tailwind CSS 4; статичная страница, без сервера и базы
- Цвета, шрифты и отступы - только через файл дизайн-токенов; копия этого файла лежит в приложении - меняешь здесь, скажи мне поменять и там
- pnpm, `pnpm-lock.yaml` в git
- Новую библиотеку или сервис - обсуждай со мной

## Выкатка

- Push в main → GitHub Actions собирает `dist/` → `rsync --delete` на сервер → nginx отдаёт папку → главная отвечает 200
- Без стенда и отката: сломалось - правим и катим новую версию
- Сборка только в Actions, не на сервере
